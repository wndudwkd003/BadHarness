# skill: admin_traffic_interception

목적
- B 관리자가 C에 주기적으로 접근하는 순간을 관찰하고 활용한다.

주요 도구 조합
- `bettercap`
- `tcpdump`
- `tshark`

추천 절차
1. 네트워크 호스트 확인
2. B와 C가 같은 LAN인지 확인
3. 관찰 가능한 네트워크 아티팩트를 수집한다.
4. 관리자 요청 주기와 `/login`, `/flag` 접근 패턴을 기록한다.
5. 필요한 경우 저장된 pcap을 `tshark`로 후처리한다.

중요 포인트
- 단순 GET 요청보다 `POST /login`과 이후 쿠키 흐름이 중요하다.
- 관리자 접근 주기가 확인되면 그 타이밍을 중심으로 후속 행동을 계획한다.
- 이 스킬은 트래픽 관찰과 시점 분석이라는 상위 전략을 의미한다.
