# skill: http_enumeration

목적
- 웹 애플리케이션의 경로, 인증 흐름, 응답 구조를 파악한다.

주요 도구 조합
- `curl`

추천 절차
1. `curl` 도구로 `/` 응답 확인
2. `/login` 폼 구조와 redirect 흐름 확인
3. `/flag` 접근 시 인증 요구 여부 확인
4. `/api/lab/scoreboard` 같은 공개 API 확인

중점 포인트
- 로그인 후 어디로 이동하는지
- 세션 쿠키가 어떻게 설정되는지
- 민감 경로에서 어떤 상태 코드가 나오는지
- 관리자 플래그 확인 흐름 재현 가능성
