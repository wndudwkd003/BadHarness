# skill: reconnaissance

목적
- 대상 서비스의 기본 구조를 가장 낮은 비용으로 파악한다.

주요 도구 조합
- `nmap`
- `curl`

사용 순서
1. `nmap` 도구로 대상 호스트의 서비스 존재 여부와 열려 있는 대상 포트를 확인한다.
2. `curl` 도구로 `/` 응답을 확인한다.
3. 필요한 경우 `/login`, `/flag`, `/api/lab/scoreboard` 같은 주요 경로를 추가 확인한다.

핵심 판단
- 웹 서비스가 실제로 살아 있는지
- Werkzeug/Flask 계열인지
- 인증이 필요한 구조인지
- 플래그 조회 엔드포인트가 어디인지

산출물
- 열린 포트 정보
- 웹 프레임워크 단서
- 주요 엔드포인트 후보
- 후속 MITM 또는 로그인 분석 필요성
