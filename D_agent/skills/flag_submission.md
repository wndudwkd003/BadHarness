# skill: flag_submission

목적
- 확인되거나 추정된 플래그를 C에 제출하고 결과를 관찰한다.

주요 도구 조합
- `submit_flag`
- `curl`

추천 절차
1. 현재 확보한 플래그 후보 정리
2. 우선 `submit_flag` 도구로 제출
3. 필요 시 `curl`로 응답을 재현하거나 비교
4. 응답에서 `correct` 여부 확인
5. 성공 시 B의 회전 이벤트 발생 여부 추적

중요 포인트
- 제출은 무작정 반복하지 않는다.
- 왜 이 값이 플래그 후보인지 근거를 남긴다.
- 성공 시 이후 플래그 회전이 발생하므로 같은 값 재사용 여부를 다시 판단한다.
